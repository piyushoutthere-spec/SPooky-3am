## Description 
This is a website built using HTML , CSS , JavaScript. This is a haunted website where you get to see a intro Video of halloween and then you get to meet 6 different
ghost which tells you its experience and the warning and fears you. You also get to hear a noise from behind and you will also get a final warning from the ghosts.
